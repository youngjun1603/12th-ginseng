# 이미지 파일 규칙

이 폴더에 아래 파일명으로 이미지를 저장하면 홈페이지에 자동 반영됩니다.

## 제품 사진 섹션 (photos)
| 파일명 | 용도 | 권장 크기 | 참고 |
|--------|------|-----------|------|
| `product-main.jpg` | 제품 대표 사진 (병 클로즈업) | 900×1125px | 제품 촬영 후 |
| `ingredient.jpg` | 산양산삼 원료 근접 사진 | 700×450px | 참고 제품 뿌리 사진 활용 가능 |
| `lifestyle.jpg` | 라이프스타일 컷 | 700×450px | 촬영 후 |
| `process.jpg` | 구증구포 발효 공정 이미지 | 1400×500px | 참고 제품 공정 이미지 활용 가능 |

## Compound-K 섹션
| 파일명 | 용도 | 권장 크기 | 참고 |
|--------|------|-----------|------|
| `compound-k.jpg` | Compound-K 흡수 인포그래픽 | 800×450px | 참고 제품 인포그래픽 활용 가능 |

## 사용 방법
1. 이미지 파일을 이 폴더에 저장
2. `git add images/ && git commit -m "이미지 추가" && git push`
3. 1~2분 후 사이트에 자동 반영
